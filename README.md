E-Commerce Sales & Delivery Performance Analysis

## Project Overview
An end-to-end data analysis project evaluating order revenue, product category performance, and how delivery delays impact customer satisfaction.

## Tools & Technologies
* **Python (Pandas, SQLite3):** Data cleaning, null handling, and delivery delay calculation
* **SQL:** Aggregations, filtering, and KPI extraction
* **Power BI:** Interactive dashboard with city slicers and KPI cards

## Key Insights & Recommendations
* **Delivery Impact:** Late orders showed lower average customer ratings compared to on-time deliveries.
* **Actionable Recommendation:** Prioritize logistics partner optimization in high-delay cities to improve customer retention.
